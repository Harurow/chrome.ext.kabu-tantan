# ADR-0016 証券会社の URL を Service Worker の外に出さない

| | |
| --- | --- |
| 状態 | 採択（2026-10-11）。**1.20.1 で実装** |
| 対象 | NFR-03, CON-04（＋ FR-06, FR-25） |
| 仕様 | [SPEC-MSG-06](../specs/messaging.md) / [SPEC-CS-28](../specs/content-scripts.md) / SPEC-SW-06 / SPEC-SW-07 |
| 発端 | TradingView の右クリック入れ子の「楽天証券で開く」が `<a href="…;BV_SessionID=<id>…">` だった。**ログイン中のセッション ID が TradingView のページ DOM に載り、ページスクリプト・計測スクリプトから読める** |

---

## 1. 右クリック入れ子の証券会社項目をどう開くか

**決定: `<a>` を持たない行にし、クリックで `*:open` を送って Service Worker が開く（「株Link」ボタンと同じ経路）。**

| 案 | 判定 |
| --- | --- |
| **(a) 採用** `<a>` を外し、行の `click` で `*:open` を送る | URL が DOM に一切出ない。ボタン側（SPEC-CS-12）で既に動いている経路の再利用で、新しい仕組みが無い |
| (b) `<a href="#">` を残し、`click` で `preventDefault` して `*:open` を送る | 却下。中クリック・Ctrl+クリック・アドレスのコピーが**`#` を開く / コピーする**誤動作になる。失う操作は (a) と同じで、壊れた操作が増える |
| (c) `<a href>` は残し、`mousedown` で直前に `href` を差し込む | 却下。差し込んだ瞬間に DOM に載る。露出の時間を縮めるだけで、なくならない |
| (d) `open-url` で URL を送る | 却下。URL を Content Script に渡す時点で 2 に反する |

## 2. `*:info` の応答に URL を載せるか

**決定: 載せない。応答は `{ available: boolean }` だけにする。**

- Content Script は注入先ページと**同じレンダラープロセス**で動く。Chrome は
  「Content Script に送ったデータはページへ漏れうると見なす」「機微な処理は Service Worker で行う」としている
  （[Stay secure](https://developer.chrome.com/docs/extensions/develop/security-privacy/stay-secure)）
- isolated world に置くだけなら DOM には出ないが、**レンダラーが侵害された場合の防壁にならない**
- 表示可否の判定に要るのは有無だけで、URL を持たせる理由が無い
- `:open` 側の応答も同じ形にそろえる（ボタンの `alert()` 判定に要るのは有無だけ）
- 拡張の更新後は旧 Content Script が切断されるため（SPEC-CS-19）、新旧の応答形式が混ざる経路は無い

| 案 | 判定 |
| --- | --- |
| **(a) 採用** `{ available: boolean }` | 上記 |
| (b) URL のまま返し、Content Script で `Boolean()` に畳む | 却下。Content Script の規律に頼ることになり、1.20.0 の欠陥と同じ形で再発しうる。**テストで「応答に秘密値が無い」と固定できない** |

## 3. 失う操作をどう扱うか

証券会社項目では、**中クリック・修飾キー付きクリック・「リンクのアドレスをコピー」が文字の上でも効かなくなる。**
FR-25 判定基準5（文字の上での非退行）に触れる。

**決定: NFR-03 を優先して受け入れる。要件側の例外は明文化済み（FR-25 判定基準5 の例外 / NFR-03。2026-10-11）。**

- いずれも URL がページの DOM にあることが前提の操作で、**URL を置かずに成立させる手段が無い**
  （中クリックを `auxclick` で拾って `*:open` を送る案は、背景タブで開く保証が無く、修飾キーの意味も再現できない。ADR-0013 の中クリックの判断と同じ）
- 「アドレスのコピー」は**セッション ID ごとコピーさせる操作**で、残す価値が無い
- ツールチップは `<span title>` で維持する

## 4. 右クリック後にログインが切れた場合

**決定: 何も開かず、`alert()` も出さない。**

- 右クリック時に `available` を確かめて項目を出している。食い違いが起きるのは「その間にタブを閉じた」場合だけ
- FR-06 は「ログインしていない場合はエラーを出さない」。ボタン側の `alert()` は FR-07「やらないこと」で
  維持しているだけで、右クリック側に広げる理由が無い
