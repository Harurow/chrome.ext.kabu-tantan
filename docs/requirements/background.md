# 背景・目的・スコープ

## 背景

日本の個人投資家は、1銘柄を調べるのに複数のサイトを行き来する。

- 証券会社サイト（楽天証券・SBI証券）— 保有状況・注文
- チャート（TradingView）
- 情報サイト（株探・MINKABU・Yahoo!ファイナンス・四季報・バフェット・コード 等）

証券会社サイトで気になる銘柄を見つけても、各情報サイトへ行くには
**銘柄コードをコピーして、サイトを開いて、貼り付けて検索する**という手間がかかる。
これを1銘柄ごとに、複数サイト分繰り返すことになる。

## 目的

**証券会社サイト・チャート上の銘柄コードから、外部の株式情報サイトへ1クリックで遷移できるようにする。**

- コピー＆ペーストと検索操作をなくす
- 遷移先は利用者が選べる（人によって見るサイトが違う）

## 利用者

| | |
| --- | --- |
| 想定利用者 | 日本株を売買する個人投資家 |
| 利用証券会社 | 楽天証券、SBI証券（一部機能で内藤証券） |
| 技術レベル | Chrome 拡張機能をインストールできる程度 |
| 規模 | 個人開発・Chrome ウェブストアで一般公開 |

## スコープ

### 対象

- 楽天証券・SBI証券のページへのリンクメニュー注入
- TradingView へのリンクメニュー注入
- 任意のページで選択した文字列に対する右クリックメニュー
- 遷移先サイトの取捨選択と並び替え

### 対象外

- 株価・財務データの取得や表示（**あくまでリンクを張るだけ**）
- 売買注文の代行・自動化
- 証券会社へのログイン処理（既にログイン済みのタブを利用するのみ）
- 楽天証券・SBI証券・TradingView 以外のサイトへの注入
- スマートフォン対応

## 前提

- 利用者は Chrome（または Chromium 系ブラウザ）を使う
- 注入対象サイトは**こちらの都合では変わらない**。仕様変更は一方的に来る
- 遷移先サイトの URL 形式も同様に一方的に変わる

## 用語

| 用語 | 意味 |
| --- | --- |
| 銘柄コード | 国内株の4桁コード（例 `7203`）。2024年以降は英字を含むものがある（例 `135A`） |
| ティッカー | 米国株の英字コード（例 `AAPL`） |
| 遷移先サイト | 株探・MINKABU 等、リンク先となる外部の株式情報サイト |
| リンクメニュー | 銘柄コードにホバーすると出るドロップダウン |
| スクリーナー | 条件で銘柄を絞り込む機能。楽天・SBI とも iframe 内で動く |
