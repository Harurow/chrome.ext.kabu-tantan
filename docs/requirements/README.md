## 経緯

この要件定義は **1.9.21 時点の実装から逆算して起こしたもの**。
先に要件があって作られたわけではないため、以下の性質を持つ。

- 「現状こうなっている」を要件として追認した項目が多い
- 本来あるべきだが未達の項目は **未達** と明記してある
- ここを起点にブラッシュアップしていく

## 書き方の約束

- 1項目1要件。複数の要求を1項目に混ぜない
- **判定可能に書く。** 「適切に」「必要に応じて」等の曖昧語を使わない
- 実現手段を書かない（「jQuery で」「MutationObserver で」は仕様側）
- 各項目に **優先度** と **対応する仕様** を書く

## 優先度

| 記号 | 意味 |
| --- | --- |
| **必須** | 満たさないとリリースできない |
| **重要** | 満たすべき。未達なら明示的な判断が必要 |
| **希望** | あると良い |
