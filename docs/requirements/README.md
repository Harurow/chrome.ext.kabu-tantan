## 経緯

この要件定義は **1.9.21 時点の実装から逆算して起こしたもの**。
先に要件があって作られたわけではないため、以下の性質を持つ。

- 「現状こうなっている」を要件として追認した項目が多い
- 本来あるべきだが未達の項目は **未達** と明記してある
- ここを起点にブラッシュアップしていく

## 書き方の約束

- 1項目1要件。複数の要求を1項目に混ぜない
- **判定可能に書く。** 「適切に」「必要に応じて」等の曖昧語を使わない
- 実現手段を書かない（「jQuery で」「MutationObserver で」は仕様側）
- 各項目に **優先度** と **対応する仕様** を書く

## 優先度

| 記号 | 意味 |
| --- | --- |
| **必須** | 満たさないとリリースできない |
| **重要** | 満たすべき。未達なら明示的な判断が必要 |
| **希望** | あると良い |

## 次バッチの対象（2026-08-23 確定 / 実データ採取後に更新）

**上から順に着手する。** 完了したら本節から消す。
順序の根拠は「単独で最後まで進められるもの」→「利用者のログイン環境が要るもの」。

| 順 | ID | 概要 | 状態 |
| --- | --- | --- | --- |
| 1 | `FR-19` | TradingView のウォッチリストの行から遷移先サイトを開けるようにする | ❌ |
| 2 | `FR-20` | 楽天証券・国内株式・株価検索でリンクメニューが出ない破損を直す | ❌ |
| 3 | `FR-23` | 検証ツールが到達できない楽天証券4ページを判定できるようにする | ❌ |

> **順序は優先度順ではない。** `FR-19` の優先度は「希望」で `FR-20`（重要）より低いが、
> `FR-20` / `FR-23` は**利用者のログイン環境がないと次の一歩が踏めない**のに対し、
> `FR-19` は 2026-08-23 の実 DOM 調査（利用者のログイン済み環境で実測）で
> 実現可能性と取り下げ条件の不成立が確定しており、**設計・実装まで単独で進められる**。
> 手が止まらない側を先に置いている。
> `FR-19` の残る未調査2件（米国株・指数の表記、仮想スクロール）は実装時の確認事項であり、
> 着手をブロックしない（FR-19 の表を参照）。
>
> `FR-20` は置き換えるセレクタを決めるために、利用者の環境で株価検索ページの
> 実 DOM を見る必要がある（手がかりはタグ名・`id`・`class` 名までしか残さないため）。
> **原因は未特定のまま**（到達は成功していて `div#line1` が 0 件、というところまで）。
> 先に片付けた `FR-22` により、次回の実行から株価検索が ⚠️ ではなく ❌ に分かれるため、
> `FR-20` の判定基準 3 を機械的に検算できる。
