# 手動確認チェックリスト

自動テストで守れない範囲を人手で確認するためのリスト。

- **所要時間の目安:** 全項目で 15〜20分 / 変更箇所だけなら 3〜5分
- **やり方:** 各項目の「操作」を実行し、「期待結果」どおりなら `[x]`、違えば `[ ]` のまま「実際」欄に何が起きたかを書く
- **報告:** このファイルをコピーして結果を書き戻すか、該当セクションだけ貼り付けて渡してください

> 全部やる必要はありません。**変更した箇所に対応するセクションだけ**やれば十分です。
> どのセクションが必要かは、下の「変更箇所 → 実施するセクション」で判断できます。

## 変更箇所 → 実施するセクション

| 変更したもの | 実施するセクション |
| --- | --- |
| `src/tradingview-cs.js` / `tradingview-cs.css` | **A**（＋楽天ログイン中なら B） |
| `src/rakuten-cs.js` / `rakuten-scr-cs.js` | **C-1**, **C-2** |
| `src/sbi-cs.js` / `sbi-scr-cs.js` | **C-3**, **C-4** |
| `src/linkMenu.js` / `src/style.css`（楽天・SBI 共通のメニュー） | **C 全体** |
| `src/service_worker.js` | **A-4**, **B**, **D** |
| `src/urls.js`（サイト追加・削除・URL変更） | **E**（＋メニュー項目数が変わるので A-7 / C / D も） |
| `src/manifest.json`（注入先・読み込み順） | **全セクション** |
| `src/options.*` | 自動テスト済み。**F** のみ |
| `src/third-party/*`（ライブラリ更新） | **A**, **C**, **F** |
| リリース前 | **全セクション** |

## 事前準備

```bash
npm run check          # まず自動テストが通ることを確認（ここが赤なら手動確認は無意味）
```

1. `chrome://extensions/` を開く
2. 「デベロッパーモード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」で `src/` を指定（既に入っていれば🔄で再読み込み）
4. 拡張機能のアイコンをクリックしてオプションページが開くこと、**全サイトが有効**になっていることを確認

> リリース前は `src/` ではなく **zip を展開したもの**を読み込んでください（`docs/TESTING.md` 参照）。

## A. TradingView（自動テスト対象外・最重要）

DOM がハッシュ付きクラス名で毎リリース変わるため、ここだけは人の目が要ります。

<https://jp.tradingview.com/chart/> を開いて実施。

### A-1. 「株Link」ボタンが出る（国内株）

- **操作:** 銘柄を `7203`（トヨタ自動車）に切り替える
- **期待結果:** チャート上部のツールバーに **「株Link」** ボタンが表示される
- [ ] OK / 実際:

### A-2. ボタンからメニューが開く

- **操作:** 「株Link」をクリック
- **期待結果:** メニューが表示される。オプションで有効にしたサイトが並ぶ（TradingView 自身は除く）
- [ ] OK / 実際:

### A-3. メニューがキャンセルできる

- **操作:** メニュー表示中に ①背景をクリック ②何かキーを押す
- **期待結果:** どちらでもメニューが閉じる
- [ ] OK / 実際:

### A-4. メニューから遷移できる

- **操作:** メニューから「株探/基本情報で開く」を選ぶ
- **期待結果:** 新しいタブで `https://kabutan.jp/stock/?code=7203` が開く（**7203 であること**）
- [ ] OK / 実際:

### A-5. 右クリックメニューが拡張される

- **操作:** チャート上で右クリック
- **期待結果:** メニュー下部に**区切り線**と「`7203` を株探/基本情報で開く」等の項目が追加されている
- [ ] OK / 実際:

### A-6. 右クリックメニューが二重に増えない

- **操作:** 右クリック → 閉じる → もう一度右クリック、を3回繰り返す
- **期待結果:** 毎回追加項目が**出る**こと、かつ増殖しない（毎回同じ数）
  > 「2回目以降に1つも出ない」も失敗です（二重防止の判定が残骸に引っかかるケース）
- [ ] OK / 実際:

### A-7. 米国株（右クリックメニュー）では対応サイトのみ出る

- **操作:** 銘柄を **`BATS:AAPL`** に切り替え、チャート上で右クリック
  > `NASDAQ:AAPL` では動きません。TradingView 側の銘柄コード取得が `TSE:` / `TSE_DLY:` / `BATS:` しか認識しないためです（既知・SPEC-TC-07）
- **期待結果:** MINKABU / 株探 / Yahoo!ファイナンス×2 / moomoo証券 の**米国株対応5サイトのみ**が追加される。四季報・株予報などは**追加されない**。TradingView 自身も出ない
  > 楽天証券にログイン中なら、先頭に「AAPL を楽天証券で開く」が**増えます**（正常）。内藤証券は米国株では出ません
- [ ] OK / 実際:

### A-7b. 米国株（「株Link」ボタン）の挙動 ※既知の不整合あり

- **操作:** 同じく `BATS:AAPL` で「株Link」ボタンを開く
- **期待結果（現状の実装どおり）:** 右クリックと違い**全サイトが並ぶ**。MINKABU / 株探 / Yahoo!×2 / moomoo は開けるが、四季報など米国株非対応のサイトは**クリックしても何も起きない**
  > こちらも楽天証券ログイン中は「楽天証券を開く」が先頭に増えます（正常）
  > これは実装の絞り込み漏れで、要件 FR-07「米国株に対応しないサイトは出さない」を満たしていません。**この項目は「上記の挙動どおりか」を見るだけで、NG 扱いにしないでください。** 修正は別タスク（SPEC-CS-12）
- [ ] 現状どおり / 実際:

### A-8. 銘柄が無い画面ではボタンが隠れる

- **操作:** チャート以外の画面（スクリーナー等）に移動する
- **期待結果:** 「株Link」ボタンが消える
- [ ] OK / 実際:

### A-9. ダーク/ライト両テーマで見える

- **操作:** TradingView のテーマを切り替える
- **期待結果:** どちらでも「株Link」の文字が背景に埋もれず読める
- [ ] OK / 実際:

## 報告フォーマット

そのまま貼り付けてもらえれば、こちらで判定して対応します。

```text
## 手動確認結果 YYYY-MM-DD / バージョン X.Y.Z

実施セクション: A, B
環境: Chrome <バージョン> / macOS

A-1 OK
A-2 OK
A-3 NG → 背景クリックでは閉じるが、キーを押しても閉じない
A-4 OK
...

その他気づいたこと:
```

**NG が1つでもあればリリースしない**でください。`NG` の内容から原因を切り分けます。
