# 手動確認チェックリスト

自動テストで守れない範囲を人手で確認するためのリスト。

- **所要時間の目安:** 全項目で 15〜20分 / 変更箇所だけなら 3〜5分
- **やり方:** 各項目の「操作」を実行し、「期待結果」どおりなら `[x]`、違えば `[ ]` のまま「実際」欄に何が起きたかを書く
- **報告:** このファイルをコピーして結果を書き戻すか、該当セクションだけ貼り付けて渡してください

> 全部やる必要はありません。**変更した箇所に対応するセクションだけ**やれば十分です。
> どのセクションが必要かは、下の「変更箇所 → 実施するセクション」で判断できます。

## 変更箇所 → 実施するセクション

| 変更したもの | 実施するセクション |
| --- | --- |
| `src/tradingview-cs.js` / `tradingview-cs.css` | **A**（＋楽天ログイン中なら B） |
| `src/rakuten-cs.js` / `rakuten-scr-cs.js` | `npm run check:selectors`（結果が ⚠️ / 未実施 の項目だけ **C** を実施） |
| `src/sbi-cs.js` / `sbi-scr-cs.js` | `npm run check:selectors`（結果が ⚠️ / 未実施 の項目だけ **C** を実施） |
| `src/linkMenu.js` / `src/style.css`（楽天・SBI 共通のメニュー） | **C 全体**（見た目は機械判定できない） |
| `src/service_worker.js` | **A-4**, **B**, **D** |
| `src/urls.js`（サイト追加・削除・URL変更） | **E**（＋メニュー項目数が変わるので A-7 / C / D も） |
| `src/manifest.json`（注入先・読み込み順） | **全セクション** |
| `src/options.*` | 自動テスト済み。**F** のみ |
| `src/third-party/*`（ライブラリ更新） | **A**, **C**, **F** |
| リリース前 | **全セクション** |

## 事前準備

```bash
npm run check          # まず自動テストが通ることを確認（ここが赤なら手動確認は無意味）
```

1. `chrome://extensions/` を開く
2. 「デベロッパーモード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」で `src/` を指定（既に入っていれば🔄で再読み込み）
4. 拡張機能のアイコンをクリックしてオプションページが開くこと、**全サイトが有効**になっていることを確認

> リリース前は `src/` ではなく **zip を展開したもの**を読み込んでください（`docs/TESTING.md` 参照）。

## A. TradingView（自動テスト対象外・最重要）

<https://jp.tradingview.com/chart/> を開いて実施。

> **TradingView にログインして実施することを推奨します。** 未ログインでは
> ツールバーの買/売ボタン領域（「株Link」ボタンの挿入先）が隠されており、
> ボタンの表示位置を正しく確認できません（SPEC-CS-12）。
